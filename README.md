# Proyecto Simulador de Organizador de Biblioteca

En este proyecto se esta realizando operaciones CRUD, simulando prestamos, categorizacion, etc..

# Operaciones realizadas con Django
- Conexion a BD con PostgreSQL
- Uso de Formularios basado en Modelos
- Configuracion con Widgets
- Creacion de validaciones personalizadas del lado del servidor
- Registro de Modelos en el panel de Administracion con configuraciones especificas
